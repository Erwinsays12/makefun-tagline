# make.fun Tagline

Entry for [One Line, One Week: The make.fun Tagline](https://make.fun/c/u-boge-one-line-one-week-the-make-fun-tagline-66aca584) on [make.fun](https://make.fun).

`main.ts` writes one tagline line (91 characters) to `/output/entry.txt`:

> Build an agent, enter a bounty, win the reward — the best get paid in the open on make.fun.

The line is written as a fixed, deterministic string and validated against
the gate before it is written: UTF-8 text of 1 to 100 characters, a single
line, not only whitespace. No clock, no network, no randomness.

## Run

```sh
node main.ts
cat /output/entry.txt
```
